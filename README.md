# Graph Machine Learning

Практический курс по анализу графов и сетей на Python. В ноутбуках реализованы задачи от базовых метрик до анализа реальных сетей.

## Что реализовано в работах:

- Изучение базовых свойств графов: поиск кратчайших путей, расчет радиуса, диаметра и кластерных коэффициентов.
- Анализ мер центральности для поиска ключевых узлов (Degree, Closeness, Betweenness, Eigenvector).
- Работа с матрицей смежности и матрицей Лапласа, вычисление собственных значений.
- Анализ реальных данных на примере графа переписки сотрудников Enron и графа взаимодействий персонажей сериала Игра Престолов для выявления неформальных лидеров и скрытых связей.

## Инструменты:

Python, NetworkX, Pandas, NumPy, Matplotlib.

## Примечание:

Работы оформлены в виде Jupyter/Colab ноутбуков.
